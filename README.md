# Swift Sport ZC32S

Le site de présentation de ma Suzuki Swift Sport ZC32S (Small Passenger, Pillar Gauge, Ma Swift Sport) et le garage (coût de la prépa, entretien, budget, carnet).

- `index.html` : la vitrine, avec le modèle 3D. Elle s'ouvre aussi en double-cliquant dessus, sans serveur.
- `garage/` : le garage (coût de la prépa), en lecture seule.
- `entretien/` : accès direct à l'onglet Entretien du garage.

Site statique, sans dépendance : servi tel quel par GitHub Pages.
